# jose-cruz-portfolio

Static portfolio for Antonio Jose Cruz II. Styles, scripts, and images are inlined in `index.html`.

GitHub Actions deploys the site with `actions/deploy-pages` on every push to `main`. In the repository settings, set **Settings → Pages → Source** to **GitHub Actions** if it is not already. After that, the site is published at https://antoniojosebcruz.github.io/jose-cruz-portfolio/.
